# Changelog

## 1.0.0

- Playback controls and a seekable progress bar above the playlist.
- Automatic production builds and direct releases on main/master pushes.

- Serialized background/shutdown persistence, private temporary files, and
  bounded debounce deadlines.

- Warm-neutral default appearance with Morandi mist-blue controls, dusty-rose reference deck,
  readable meters, and restrained motion.
- Single-click playback, explicit A/B comparison, and direct EQ on/off controls.
- Short waveform transitions with reduced-motion support and cancellation.
- Universal Mac builds and Windows x64 installer configuration.
